# EduBoard – Student Progress Dashboard

A responsive student dashboard built with HTML, CSS, and a bit of JS.  
Displays GPA, Attendance, Subjects, Deadlines, and Profile info.

## Features
- Responsive sidebar and cards
- Clean, modern UI
- Progress tracking via tables
- Upcoming deadlines section
- Profile & Settings pages
